PASO 1 — PUBLICAR LA PARTE VISUAL EN GITHUB PAGES
1. Crea un repositorio público en GitHub, por ejemplo prov910-web.
2. Sube el contenido de esta carpeta (index.html, styles.css, app.js, assets, etc.) a la raíz del repositorio.
3. En GitHub entra en Settings > Pages.
4. En Build and deployment elige Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera a que GitHub Pages publique la web.

PASO 2 — ACTIVAR CUENTAS Y FORMULARIO DE LA GUÍA CON SUPABASE
1. Crea un proyecto en https://supabase.com/.
2. En Project Settings > API copia Project URL y anon/public key.
3. Abre app.js y pega esos valores en SUPABASE_URL y SUPABASE_ANON_KEY.
4. En Supabase > SQL Editor ejecuta supabase/schema.sql.
5. En Authentication > URL Configuration añade la URL publicada en Site URL y Redirect URLs.
6. Revisa el proveedor Email y activa la confirmación de correo si procede.
7. Despliega las Edge Functions indicadas más abajo.

PASO 3 — ACTIVAR PAGOS REALES CON STRIPE
Necesitas una cuenta Stripe verificada y una función de servidor. No pongas nunca la clave secreta de Stripe en app.js ni en ningún archivo público.

1. Crea una cuenta en https://stripe.com/.
2. Instala Supabase CLI y vincúlala al proyecto: supabase link --project-ref TU_PROJECT_REF.
3. Configura secretos en Supabase Functions:
   supabase secrets set STRIPE_SECRET_KEY=sk_test_... SITE_URL=https://TU_USUARIO.github.io/TU_REPOSITORIO SUPABASE_URL=https://TU_PROYECTO.supabase.co SUPABASE_ANON_KEY=TU_ANON_KEY SUPABASE_SERVICE_ROLE_KEY=TU_SERVICE_ROLE_KEY
4. Despliega:
   supabase functions deploy create-checkout
   supabase functions deploy stripe-webhook --no-verify-jwt
5. En Stripe crea un webhook que apunte a:
   https://TU_PROYECTO.supabase.co/functions/v1/stripe-webhook
   Suscríbelo al evento checkout.session.completed.
6. Copia el secreto whsec_... y configúralo:
   supabase secrets set STRIPE_WEBHOOK_SECRET=whsec_...
7. Haz primero pagos de prueba con las claves sk_test_ y una tarjeta de prueba de Stripe.
8. Solo después de verificar pedidos, importes, impuestos, envíos y devoluciones, cambia a claves live.

ATENCIÓN: la función de checkout usa los precios configurados en supabase/functions/create-checkout/index.ts. Actualiza el catálogo y los importes ahí si cambias los precios de la web. Configura impuestos, dirección de envío, gastos de envío y política de devoluciones antes de aceptar pagos reales. El prototipo actual no cobra gastos de envío ni calcula IVA por separado.

FOTOGRAFÍAS DE PRODUCTOS
- El primer producto utiliza la fotografía que adjuntaste en esta conversación, centrada y ajustada con object-fit: contain para no deformarla.
- Las otras tres imágenes se cargan desde la CDN de Everful a partir de los enlaces de producto que facilitaste. Necesitan conexión a internet y podrían cambiar o dejar de estar disponibles. Confirma con el proveedor que puedes utilizarlas comercialmente o sustitúyelas por fotografías propias autorizadas.

DATOS Y COPIAS DE SEGURIDAD

- Las cuentas y pedidos, una vez conectado Supabase, se guardan en el proyecto Supabase.
- No hay sincronización de cesta entre dispositivos.
- Exporta y conserva los datos del proyecto Supabase y no compartas las claves privadas.
